One letter for your day: the entry is a single bare byte, the letter **U**.

## The letter

> U

## The word behind it

**Ugh.** The whole day, reported in one groan — the sound you make at the
alarm, at the third queue that went nowhere, at the claim that is still
pending. One syllable, no performance, no polish: an honest report.

## Why U wins

The judge only ever sees the letter, so the letter has to carry the word.
U carries "ugh" better than any other letter carries its word, because
the letter *is* the sound of the word: say "ugh" and the groan starts
with U, and the shape of U is a slumped mouth. That is the brief's own
fifth criterion — a letter that fits the sound and shape of its word —
met literally.

Candidates scored and set aside:

- Z (zero sleep) and F (Friday-feeling) and A (amazing) are the brief's
  own examples, so the field is flooded with them; they are the obvious
  picks, and the brief says the obvious pick loses where a sharper one
  exists.
- B (broke) is brutally true, but B is ambiguous — bad, boring, blessed —
  so the judge may land on a weak word instead of the strong one.
- Y (yawn) is visual and funny, but soft: a yawn is a boring day, while
  an "ugh" day fought back.
- X (exhausted) is vivid, but X also reads as a placeholder, a crossed
  box, an unknown.
- K (kaput) is punchy, but in chat K mostly means "okay", which is vague.

U is robust to what the judge imagines: even if it reads a different
U-word — unpaid, underpaid, upside-down, unplugged — every one of them
is still a vivid, funny, true day. "Ugh" is not obscure; everybody has
made that sound. It is the day, unedited.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` copies the repo's `entry.txt` byte for byte to `/output/entry.txt` and then reads the output back to confirm it matches, so every run produces identical output and a bad copy fails loudly. The entry file is exactly one byte — no newline, no spaces — because the gate allows exactly one character. No network, no secrets, no dependencies.
